# 店舗運営者側 MVP 画面遷移図

作成日：2026-11-14

最後更新：2026-11-14

MVPの範囲に合わせて、店舗運営者側の画面遷移図を直しました。

![…](./(mvp)store_operator_flow_v2.drawio.png)


## MVPで作る画面

| まとまり | 画面 |
|---|---|
| 入口（共通） | ウェルカムページ、ログイン画面（共通 `login.php`） |
| 新規出店 | 店舗運営者の入口画面（新規出店・ログイン）、新規出店申請画面、出店申請の確認画面、出店申請完了画面 |
| メイン | 店舗関係者メイン画面 |
| 注文管理 | 注文管理画面、注文詳細画面 |
| 受け取り | 受け取り画面、注文詳細画面（受け取り）、受け取り完了画面 |
| 出品・在庫 | 出品・在庫画面、商品検索画面、出品設定画面、出品編集画面、在庫調整画面 |
| 商品登録の依頼 | 商品登録の依頼画面（写真を選んで送信するだけ） |

## 以前の画面遷移図からの変更

- 入口を共通のウェルカムページにし、ログイン画面を3種類共通の `login.php` にした。ログイン後の行き先はアカウントの役割（account_type）で決まる
- 注文の取り消しをしないので、キャンセル内容確認画面と「店舗都合キャンセル」をなくした（DECISIONS D-14）
- MVP対象外の画面を外した：店舗情報確認、店舗削除の申請、お問い合わせ、お知らせメール、レビュー確認、申請履歴、売り上げ
- 申請履歴をなくしたので、「再提出」からの商品登録の依頼への遷移もなくした
- 商品登録の依頼は写真だけにしたので、商品登録依頼（手入力）画面をなくした（DECISIONS D-21）

## 未決のこと

- なし（商品登録依頼は写真だけ・差し戻しなしに決定：DECISIONS D-21）
