# システム管理者側 MVP 画面遷移図

作成日：2026-11-14

最後更新：2026-11-14

MVPの範囲に合わせて、システム管理者側の画面遷移図を直しました。

![…](./(mvp)system_admin_flow_v2.drawio.png)


## MVPで作る画面

| まとまり | 画面 |
|---|---|
| 入口（共通） | ウェルカムページ、ログイン画面（共通 `login.php`） |
| メイン | 管理者メイン画面 |
| 店舗管理・新規出店申請の管理 | 店舗管理画面、出店申請の審査画面 |
| 商品マスター | 商品マスター画面、商品マスターの編集画面 |
| 商品登録依頼 | 商品登録依頼画面、依頼の写真の確認画面、商品マスター登録画面 |

## 以前の画面遷移図からの変更

- 入口を共通のウェルカムページにし、管理者ログイン画面を3種類共通の `login.php` にした。ログイン後の行き先はアカウントの役割（account_type）で決まる
- MVP対象外の画面を外した：アカウント管理（詳細・停止）、お問い合わせ、レビュー管理、FAQ管理、削除申請の審査
- OCR（写真の読み取り）は作らないので、「読み取り結果を使って入力」をなくした。管理者が写真を見て手で登録する（DECISIONS D-20）
- 差し戻しはしないので、修正依頼画面をなくした。登録できない依頼は「登録しない」にする（DECISIONS D-21）

## 未決のこと

- なし（OCRは作らない：D-20、商品登録依頼は写真だけ・差し戻しなし：D-21）
