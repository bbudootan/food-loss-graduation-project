v3では、固定Sidebarを廃止し、マイページを個人の活動実績を可視化するダッシュボード形式に再設計した。

また、TABETEとの差別化を意識し、「レスキュー」に依存した表現を見直することも検討中。（暫定名：「アクション」）

| エリア | 機能・設計方針 |
|---|---|
| ① マイステータス | アバター・ユーザー名・会員レベル・経験値・保有ポイントを表示し、次のレベルまでの進捗を可視化する。|
| ② マイメニュー | 注文履歴・お気に入り・クーポン・設定など、利用頻度の高い機能へのショートカットを配置する。|
| ③ これまでの取り組み | 累計購入回数・食品ロス削減量・CO₂削減相当量など、ユーザーの貢献実績を数値で表示する。|
| ④ エコアクショントロフィー | アクション回数に応じた達成記録や獲得バッジを表示し、達成感と継続利用への意欲を高める。|
