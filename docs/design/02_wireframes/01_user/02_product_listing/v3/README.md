# 商品一覧 — Wireframe v3



## 2-1. 商品から探す/商品一覧ページ

| エリア | 機能・設計方針 |
|---|---|
| ① キーワード検索 | 商品名やキーワードによる検索機能を提供する。 |
| ② 絞り込み条件 | エリア・カテゴリ・受取時間・価格帯を指定し、複数条件による検索を可能にする。選択中の条件は個別に解除できる。 |
| ③ 検索結果・表示設定 | 該当件数を表示し、新着順・価格順・受取時間順などで並び替える。 |
| ④ 商品表示エリア | - |
| ⑤ 表示切替（一覧・地図） | 商品表示エリアの表示形式を「一覧表示」と「地図表示」で切り替える。「一覧表示」では出品中の全商品をグリッド形式で表示し、商品写真・価格・店舗名・受取時間・残数を確認できる。「地図表示」では出品中の商品がある店舗の位置を地図上にピンで表示し、ピンをクリックすると、その店舗で購入可能な商品を確認できる。検索・絞り込み条件は両表示で共通とする。 |

※ ⑤の表示切替機能により、④の商品表示エリアを「一覧表示（グリッド表示）」と「地図表示」で切り替えられる。検索条件・絞り込み条件は両表示で共通とする。

商品一覧ページと店舗一覧ページの地図表示には共通のMapコンポーネント（COMMON MAP COMPONENT）を使用する。

検索条件や表示対象、ピン選択時の情報は各ページの目的に応じて切り替えることで、機能の重複を避け、UIの一貫性と開発効率を高める。
