## v4の変更点と設計意図

- **レイアウトの統一：** v3の小規模な画面構成を見直し、他のユーザー向けページと同じ画面幅を採用。中央配置のログインカードにより、入力フォームの視認性と操作性を改善した。
  
- **共通レイアウトとの役割分担：** Header・Footerは共通レイアウト側で管理し、本ページではログインに必要なメインコンテンツのみを設計した。
  
- **パスワード再設定フローの明確化：** 「メール送信」「新しいパスワードの設定」「設定完了」を独立した画面として整理し、各操作後の遷移先を明確にした。
  
- **入力検証・エラー表示：** 必須項目の未入力、認証失敗、パスワードの不一致などに対応するエラー表示を設計に追加した。
