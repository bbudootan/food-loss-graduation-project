## 共通レイアウトとの役割分担

ヘッダー・フッター・通知／カート／アカウントのドロワーは[共通レイアウト v4](../../00_common/v4/README.md)を使用し、以下の図はそのメインコンテンツ領域に配置する。図で共通部分が省略されていても、実装時は組み合わせて表示する。

共通アカウントドロワーと[マイページ](../../06_mypage/v4/README.md)の「設定」は、同じ会員向けの本ページへ接続し、ドロワーからの遷移時はドロワーを閉じる。プロフィール編集、メールアドレス変更、再設定メール送信、退会への入口はページ側で管理し、ドロワー内に設定フォームを重複して作らない。保存済みのニックネームは共通アカウントドロワーにも反映する。

| やりたいこと | 操作 |
|---|---|

## 2. メールアドレス変更（ログイン情報カード内そのまま）

「変更する」を選ぶと、登録メールアドレス欄を以下のフォームに切り替える。プロフィール欄とパスワード再設定の案内はそのまま表示する。

```
┌──────────────────────────────────────────────────────────────────────┐
│  メールアドレスの変更                                                  │
│                                                                      │
│  現在のメールアドレス：user@example.com                                │
│                                                                      │
│  新しいメールアドレス（必須）                                           │
│  [ new@example.com                                    ]              │
│                                                                      │
│  現在のパスワード（必須）                                              │
│  [ パスワードを入力                         ] [表示/非表示]            │
│                                                                      │
│  新しいアドレス宛てに確認メールを送ります。                              │
│  メール内のリンクで確認が完了するまで、                                  │
│  現在のメールアドレスが有効です。                                       │
│                                                                      │
│                    [キャンセル]  [変更確認メールを送る]                 │
└──────────────────────────────────────────────────────────────────────┘
```

## 3. 覚えておくこと

- **名前は公開されます。** 保存すると、マイページやレビューにも新しい名前が表示されます。
- **メールは、リンクで確認した後に変わります。** それまでは今のアドレスを使います。メールが届かないときは、再送や入力のやり直しができます。
- **パスワードは12文字以上です。** 変更後は、もう一度ログインします。[ログイン画面の再設定方法](../../12_login/v4/README.md)と同じ流れです。
- **退会すると、ポイントやゲームの記録は使えなくなります。** 設定ページのボタンを押しただけでは退会になりません。

## 4. 操作中の表示

- 名前は入力が必要です。メールを変えるときは、新しいアドレスと今のパスワードも入力します。
- 名前の保存とメールの送信は、それぞれのボタンで行います。完了するまでは、同じボタンを押せません。
- 完了したら「保存しました」「メールを送りました」などのメッセージを表示します。
- 入力ミスは、入力欄の下に理由を表示します。読み込みや送信に失敗したときは、やり直せるようにします。
- 保存前に別のページへ移動するときは、「保存せずに移動してよいか」を確認します。
