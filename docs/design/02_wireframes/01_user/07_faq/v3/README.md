本ページは、ユーザーガイドと簡易的なFAQ（よくある質問）の両方の役割を持たせる。
FAQはトグル式のリスト（アコーディオン形式）で表示し、各質問をクリックすると、その場で回答が展開される仕様とする。
また、回答内には可能な限り関連ページへの直接リンクを設置し、ユーザーが必要な情報や機能にスムーズにアクセスできるようにする。
