## 共通レイアウトとの役割分担

ヘッダー・フッター・通知／カート／アカウントのドロワーは[共通レイアウト v4](../../00_common/v4/README.md)を使用し、以下の図はそのメインコンテンツ領域に配置する。図で共通部分が省略されていても、実装時は組み合わせて表示する。

商品画像の切替、価格・在庫・受取情報、お気に入り、数量選択、カート追加は本ページ側で管理する。商品詳細は独立したページであり、共通ドロワー内には配置しない。カート追加の結果は共通カートドロワーにも反映し、「店舗情報」は[店舗詳細](../../05_store_detail/v4/README.md)への導線とする。
