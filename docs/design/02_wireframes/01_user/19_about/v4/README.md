## 共通レイアウトとの役割分担

ヘッダー・フッター・通知／カート／アカウントのドロワーは[共通レイアウト v4](../../00_common/v4/README.md)を使用し、以下の図はそのメインコンテンツ領域に配置する。図で共通部分が省略されていても、実装時は組み合わせて表示する。

本ページは共通フッターの「運営について」から開く公開ページで、未ログインでも閲覧できる。プロジェクトの写真・理念、サービスの仕組み、現在と将来の取り組み、お問い合わせとページ上部への導線はページ側で管理し、共通ナビゲーションはそのまま使用する。
