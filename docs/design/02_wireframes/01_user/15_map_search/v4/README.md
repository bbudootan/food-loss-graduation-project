## 地図で探そうページ

| エリア | 機能・設計方針 |
|---|---|
| ① モード切替 | 「商品から探す」「店舗から探す」の2つの検索モードを切り替える。選択したモードに応じて、検索条件・地図上の表示対象・検索結果カードの内容を変更する |
| ② キーワード検索 | 商品名・店舗名・キーワードなどから検索できる。検索対象は選択中のモードに応じて切り替える |
| ③ 絞り込み条件 | 商品モードでは「エリア・カテゴリ・受取時間・価格帯」、店舗モードでは「エリア・店舗ジャンル・出品状況」などの条件で絞り込む |
| ④ 地図表示エリア | 検索条件に一致する店舗の位置を地図上にピンで表示する。地図の拡大・縮小、移動、現在地への移動に対応し、ピンを選択すると対象の情報を確認できる |
| ⑤ 検索結果カードエリア | 選択したピンに対応する商品・店舗情報をカード形式で表示する。商品モードでは商品名・価格・受取時間など、店舗モードでは店舗名・ジャンル・出品状況などを表示し、それぞれの詳細ページへ遷移できる |

### v4 新規追加の背景と設計意図

- 従来は商品一覧ページ・店舗一覧ページのそれぞれに地図表示を設けていたが、画面遷移図を整理する中で、地図探索機能が複数ページに分散しており、構造が分かりにくいという課題が明らかになった。
  
- そこで v4 では、地図を使った探索体験を「地図で探そう」ページに集約し、商品一覧・店舗一覧の役割を明確に分離した。
  
- 本ページでは、「商品から探す」と「店舗から探す」を切り替えながら、現在地やエリアをもとに地図上で直感的に検索できる構成とした。
  
- これにより、一覧ページは比較・閲覧に特化し、地図ページは周辺探索に特化するという、役割の明確なUI構造を実現している。
