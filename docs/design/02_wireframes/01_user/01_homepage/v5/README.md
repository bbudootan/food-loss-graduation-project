## 商品カード

商品説明はカード裏面に集約し、独立した商品詳細ページは設けない。

- **写真**：1商品1枚。1:1画像を引き伸ばさず中央でトリミングし、当面は5:4の枠で約80％を表示する。料理の見え方を優先して高さを確保し、比率・高さは実装後に調整可。
- **表面**：商品名・価格・受取時間帯・残数・数量変更・カート追加を表示。情報の入口は「店舗名」→店舗詳細ページ、「商品について」→裏面の2つ。
- **裏面**：商品説明・アレルゲン・食品期限・保存方法を表示。操作は「商品に戻る」→表面の1つ。正反面は同じ高さとし、長文は内容領域だけ縦スクロール、戻るボタンは下部に固定する。
- **売り切れ**：MVPではカード全体を減光し、「売り切れ」のみ強調。店舗名リンク・裏返しを含むすべての操作を無効化し、クリック・Tab操作の対象から外す。裏面表示中に売り切れを検知した場合も、表面へ戻してから無効化する。
- **受取場所・方法**：商品情報の項目として廃止。受取は全店で店頭受取・共通手順とする。

## 店舗カード

店舗カードは横長とし、広い画面では1行2枚を表示する。商品カードは縦長・1行3枚とし、両者の役割と見た目を区別する。

| 表示項目 | 内容 |
|---|---|
| 店舗写真・お気に入り | 写真領域と店舗のお気に入り操作 |
| 出品状況 | 「出品中：○件」または「現在出品なし」 |
| 店舗名・ジャンル | 店舗情報の見出し |
| エリア・距離 | エリアと現在地からの距離 |
| 営業時間 | 店舗の開店・閉店時刻から表示する |
| 詳細への入口 | 「店舗情報を見る」 |

- **店舗共通の「受取可能時間帯」は表示・保持しない。** 出品ごとに受取条件や締切が異なるため、店舗カードに固定の受取時間帯を持たせない。
- 店舗の表示用データは `businessHours` を残し、`pickupHours` を削除する。
