### 本文の構成（暫定）

| 本サービスについて | 補足 |
|---|---|
| 会員登録・アカウント | - |
| 注文・お支払い・受け取り | 返金条件などを記載 |
| ポイント・ミニゲーム | ポイントの獲得と利用（注文時の割引または公益への寄付）、ゲーム報酬、および注文キャンセル時のポイントの取り扱いを記載 |
| レビュー・通報 | レビュー対象、禁止される不適切な内容、通報の方法、管理者によるコメントの公開/非表示を記載 |
| 禁止事項・利用制限 | 虚偽の投稿、悪意ある通報の繰り返し、ポイントの不正取得などを記載 |
| 退会・サービスの変更 | 退会時にポイントおよびゲーム記録が自動的に失効し、復元できない旨を記載 |
