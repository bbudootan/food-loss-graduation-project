# 店舗一覧 — Wireframe v3



## 2-2. 店舗から探す/店舗一覧ページ

| エリア | 機能・設計方針 |
|---|---|
| ① キーワード検索 | 店舗名・駅名・住所などのキーワードによる検索機能を提供する。 |
| ② 絞り込み条件 | エリア・店舗ジャンル・出品状況を指定し、複数条件による検索を可能にする。選択中の条件は個別に解除できる。 |
| ③ 検索結果・表示設定 | 該当店舗数を表示し、店舗名順・出品数順などで並び替える。 |
| ④ 店舗表示エリア | 初期状態では公開中の全店舗を表示。店舗写真・店舗名・ジャンル・所在地・出品状況を確認でき、店舗情報ページへ遷移する。 |
| ⑤ 表示切替（一覧・地図） | 「一覧表示」と「地図表示」を切り替えられる。地図上のピンをクリックすると店舗の概要を表示し、店舗情報ページへ遷移できる。検索・絞り込み条件は両表示で共通とする。 |

商品一覧ページと店舗一覧ページの地図表示には共通のMapコンポーネント（COMMON MAP COMPONENT）を使用する。

検索条件や表示対象、ピン選択時の情報は各ページの目的に応じて切り替えることで、機能の重複を避け、UIの一貫性と開発効率を高める。
