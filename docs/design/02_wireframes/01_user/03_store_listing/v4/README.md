## 共通レイアウトとの役割分担

ヘッダー・フッター・通知／カート／アカウントのドロワーは[共通レイアウト v4](../../00_common/v4/README.md)を使用し、以下の図はそのメインコンテンツ領域に配置する。図で共通部分が省略されていても、実装時は組み合わせて表示する。

キーワード検索、絞り込み、並び替え、店舗カードと追加表示は本ページ側で管理する。ヘッダーの「店舗一覧」は本ページへの入口であり、カードの「店舗情報を見る」は[店舗詳細](../../05_store_detail/v4/README.md)へ進むページ内の導線とする。

## 店舗一覧ページ

| エリア | 機能・設計方針 |
|---|---|
| ① キーワード検索 | 店舗名・駅名・住所などのキーワードによる検索機能を提供する。 |
| ② 絞り込み条件 | エリア・店舗ジャンル・出品状況を指定し、複数条件による検索を可能にする。選択中の条件は個別に解除できる。 |
| ③ 検索結果・並び替え | 該当店舗数を表示し、店舗名順・出品数順などで並び替える。 |
| ④ 店舗表示エリア | 店舗カードのグリッド形式で公開中の全店舗を表示。店舗写真・店舗名・ジャンル・所在地・出品状況を確認でき、店舗情報ページへ遷移する。 |

### v4の変更点と設計意図

v3では店舗一覧ページ内に地図表示を含めていたが、v4では店舗一覧を「参加店舗を比較・閲覧するための一覧ページ」として再整理した。
