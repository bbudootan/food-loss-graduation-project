## 共通レイアウトとの役割分担

ヘッダー・フッター・通知／カート／アカウントのドロワーは[共通レイアウト v4](../../00_common/v4/README.md)を使用し、登録フォームはそのメインコンテンツ領域に配置する。v3図上部のロゴと「ホームへ戻る」は、共通ヘッダーのロゴ・ホームへの導線として扱い、ページ独自のヘッダーを重ねて実装しない。共通ドロワーは未ログイン状態の表示を使用する。

ニックネーム・メールアドレス・パスワードの入力、[利用規約](../../17_terms/v4/README.md)・[プライバシーポリシー](../../18_privacy/v4/README.md)への同意、登録確認メールの送信、[ログイン](../../12_login/v4/README.md)への導線は本ページ側で管理する。
