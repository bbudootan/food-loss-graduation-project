![ワイヤーフレーム](./welcome_page.png)

## 1. 画面のポイント

- 一般利用者が商品を探しやすいよう、商品閲覧を主な入口とする。
- 背景はイメージした淡いイラスト。自作または利用条件を確認した素材を使用し、文字の読みやすさを優先する
- 「商品を探す」からホームへ進む。ログインなしで閲覧できる
- 「店舗運営者の方」は新規出店・ログインの選択画面へ、「管理者の方」はログイン画面へ進む
- ログイン後の遷移とアクセス権限は、選択した入口ではなくアカウントの役割に基づいて判定する

関連資料：[共通入口とログインの方針](../../../03_screen_flow_diagrams/00_welcome_page/README.md)
