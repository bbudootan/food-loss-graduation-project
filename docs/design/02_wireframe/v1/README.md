# ユーザー向けのフロントエンド

作成日：2026-10-05（月）

## 1. ホームページ

### 全体レイアウトと機能別説明
画面は大きく以下の六つのエリアで構成する。
```
┌──────────────────────────────────────────────┐
│ ① Header                                     │
│ Logo / Location / Weather 　　　　          　│
├─────────────┬────────────────────────────────┤
│ ② Sidebar　☰│ ③ Campaign Banner              │
│             ├────────────────────────────────┤
│             │ ④ Recommend for today          │
│             ├────────────────────────────────┤
│ User        │                                │
│ Notification│ ⑤ Search & Filter              │
│ Navigation  │   & Rescue Item Grid           │
│             │                         🎯 　　│
│             │                   ⑥ Mini Game  │
└─────────────┴────────────────────────────────┘
```
① Header：サービス名・ロゴ/現在地または設定エリア/天気情報を表示。現在地を基準として、ユーザーが受け取り可能な店舗・商品を探しやすくする

② Sidebar：主なユーザー情報と主要機能へのナビゲーションをまとめる
　★検討中：マイページの実績可視化はここに移行（レスキュー回数、バッジ、CO₂削減量、植えた木の数...）
 
③ Campaign Banner：ホーム画面上部に大きなキャンペーンエリアを配置。季節限定キャンペーン、イベント情報、広告を表示

④ Recommend for today：ホーム画面の中心となる機能。ユーザーのエリアや利用履歴などをもとに、現在購入可能なおすすめ商品を表示する

⑤ Search & Filter & Rescue Item Grid：商品数が増えた場合でも探しやすいように検索・絞り込み機能を設置する⇒地図を開くと出品中の店を簡単に見られる⇒商品グリッドで残り個数・受取時間・現在地からの距離など詳細情報を確認できる。

⑥ Mini Game： 画面右下に固定型のミニゲーム入口を設置する。毎日のミニゲームを通じて楽しみながら継続利用できる仕組み。1日2回プレイ可能
