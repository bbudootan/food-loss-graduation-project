# 初期ユーザー向けの UI スケッチ

作成日：2026-09-24（木）

このフォルダには、JEC Food Rescueの初期設計段階で作成した手書きスケッチを保存しています。

これらは最終デザインではなく、画面構成や機能のアイデアを整理し、後のFigma Wireframe制作につなげるために作成したものです。

---

## Sketch 01 ： ホームページ、商品カードとミニゲーム

ファイル：`2026-09-24_homepage_game_item_sketch.jpeg`

### 主な検討内容

- Homepage全体の基本レイアウト
- サイドバーナビゲーション構成
- おすすめレスキュー商品の表示
- 商品カードおよび商品グリッドの表示方法
- お気に入りボタン
- ミニゲームの入口
- ミニゲームの仕組み：ルート・マス・ルーレット・くじなどの報酬機能
- 商品評価表示

ホームページ上で、ユーザーが商品を探すだけではなく、楽しみながらサービスを継続利用できる仕組みについて検討しました。

---

## Sketch 02 ： マイページと退会フロー

ファイル：`2026-09-24_mypage_sketch.jpeg`

### 主な検討内容

- ユーザープロフィール
- レスキューレベル
- レベル進捗
- ポイントカード
- 個人情報確認・編集
- Trophy / Achievementなどレスキュー実績の表示
- 退会ページ
- 退会確認フロー

マイページでは、単なるアカウント設定画面ではなく、ユーザー自身のレスキュー活動や成長を確認できるページを目指しています。

---

## Sketch 03 ： 購入履歴 / カート / 問い合わせ / FAQ

ファイル：`2026-09-24_subpages_sketch.jpeg`

### 主な検討内容

- 購入履歴ページ
- 再注文機能
- レビュー投稿
- 商品ステータス表示
- カートページ
- 購入までのステップ表示
- 問い合わせフォーム
- FAQ ページ

ホームページやマイページ以外に必要となる補助機能・サブページについて初期アイデアを整理しました。

---

## 今後の予定

これらの手書きスケッチをもとに、Figma上でより具体的なWireframeを作成します！

必要に応じてレイアウトや機能を修正し、
各ページの UI を段階的に改善していく予定です。
