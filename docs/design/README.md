# UI / UX デザイン資料

このディレクトリでは、JEC Food RescueのUI/UXデザイン制作過程を管理します。

完成した画面だけではなく、初期アイデア、手書きスケッチ、ワイヤーフレーム、モックアップなどを保存し、どのように画面構成や機能を検討・改善してきたかを確認できるようにします。

## ディレクトリ構成

### 01_sketches

初期段階で作成した手書きスケッチや画面アイデアを保存します。

---

### 02_wireframes

テキスト（ASCII）ワイヤーフレームを、**利用者の種類 → ページ → バージョン** の階層で管理します。

- `01_user`：一般利用者向け。各画面の `v1`、`v2`、`v3`、`v4`を元の番号のまま保持します。
- `02_store_operator`：店舗運営者向け。
- `03_system_admin`：システム管理者向け。

現在の全ページ・バージョン一覧は [Wireframes](./02_wireframes/README.md) を参照してください。

### 04_mockups

ワイヤーフレームをもとに作成した、Figmaで作成したより完成形に近いUIデザインを保存します。

ここでは主に以下の内容を検討します。

- 配色
- フォント
- アイコン
- 写真・イラスト
- カードデザイン
- ボタンデザイン
- ブランドイメージ
- 画面全体のビジュアル表現

---

## デザイン方針

本プロジェクトでは、最初から完成形を決めるのではなく、
手書きスケッチ → ワイヤーフレーム → モックアップ → 実装
という流れで段階的にデザインを改善していきます。
デザイン変更の履歴を残すことで、なぜそのレイアウトや機能を採用したのかを後から確認できるようにします。
