## 現在の進捗状況

- **確認日：2026-10-25**。以下の状態は、このリポジトリで確認できる成果物に基づきます。
- **既存成果：** 3種類の利用者向けワイヤーフレームと画面遷移図があります。画面間には一部仕様の差分が残っています。
- **現在の段階：** 主線の仕様をそろえ、HTML / CSS / JavaScriptで操作できる最小構成へ移る段階です。主線の動作コードはまだ確認できていません。

## 今後の進め方

**既存ワイヤーフレーム → 必要な仕様の確認 → 主線をコードで試作・検証 → 同じ主線をバックエンド・DBへ接続 → 周辺機能と見た目を改善** の順で進めます。

- ワイヤーフレームは、ページ構成・主要操作・操作結果が説明できれば実装に進めます。未解決の箇所だけ、短いメモや図を補います。
- ワイヤーフレームをもとに、[frontend/](../../frontend/README.md)でHTML/CSS/JavaScriptによるフロントエンド開発を開始し、主線の実装と検証を進めます。
- 色・文字・余白・ボタン・入力欄は、主線の実装中に必要な共通スタイルからそろえます。
