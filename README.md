# food-loss-graduation-project
本プロジェクトは、食費を抑えたい方や環境問題に関心のある方を対象に、ゲーミフィケーションを通じてフードロス問題に取り組む卒業制作です。日々の買い物を「目に見えるエコな成果」へと変え、ゲーム感覚で楽しみながら継続的な環境貢献を実現します。

## システムを開発したい理由および取り巻く背景・課題等

日本では、まだ食べられるにもかかわらず廃棄される「フードロス」が大量に発生しています。フードロスは、食品そのものが無駄になるだけでなく、廃棄・焼却にかかるコストや、処理の過程で発生する温室効果ガスなど、経済面・環境面の両方に負担を与える問題です。

特に飲食店、パン屋、スーパーなどでは、営業時間内に売り切れなかった商品や、当日中に販売する必要がある商品が廃棄されることがあります。店舗側にとっては、これらの商品を少しでも販売できれば、廃棄量や処分コストを減らすことができます。また、環境保全に取り組む店舗としてのPRや、新しい顧客との接点をつくる効果も期待できます。

一方、利用者側には、食品を通常より安く購入したいというニーズがあります。特に、学生や若い社会人、家庭を持つ人など、日常の食費を抑えたい利用者にとって、まだ十分食べられる食品を手頃な価格で購入できることは大きなメリットになります。また、環境問題に関心はあっても、「具体的に何をすればよいか分からない」「エコ活動を継続するのが難しい」という人も少なくありません。

## システムを開発する目的・ゴール

- **店舗で販売しきれない食品と利用者をマッチングし**、利用者が手頃な価格で食品を購入できる仕組みを提供します。
- **ゲーム要素と環境貢献の可視化**を取り入れることで、利用者が継続してフードロス削減に参加したくなる仕組みを目指します。商品を購入することでゲームのプレイ回数やポイントを獲得でき、ゲームを進めることでクーポンや「木」などの報酬を得られるようにします。獲得した木は日本地図上で育てることができ、将来的には実際の植樹活動や環境保全活動との連携も検討します。（e.g. 将来はNPOや環境組織と提携し、一部の収益やsponsor budgetがreal-world tree planting/urban greeningに使わる）

以上のように、本システムは、**店舗の食品廃棄を減らすこと、利用者が食品をお得に購入できること、そして楽しみながら継続的に環境活動へ参加できること**の3つを同時に実現することを目的とします。

## 既存サービス「TABETE」との差別化

既存サービス「TABETE」では、食品のレスキューによって経験値を獲得し、「ヒーローレベル」の上昇やポイント・特典などを通じて継続利用を促している。

一方、本システムでは、独立した会員ランクやEXP制度を設けず、**ミニゲームのマップ探索と「わたしの森」への成果の蓄積**を中心としたゲーミフィケーションを採用する。

食品の購入・受取をゲームへの参加機会につなげ、マップを進めることでポイントやクーポン、苗木などの報酬を獲得できる仕組みを目指す。獲得した苗木を自分の森に植え、活動の成果を視覚的に積み重ねることで、**食品ロス削減への参加を、単発の購買行動から、楽しみながら継続できる体験へと発展させること**を目指す。
